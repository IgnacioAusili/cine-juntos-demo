Cómo alojar y compartir un video

          

          
        

        

          

            Para poder cargar un video, se necesita un enlace HTTPS directo a un archivo de video. Acepta MP4, WebM, Ogg, MOV y M4V; el enlace debe abrir el archivo, no una página de reproducción.
          

          

            
Cómo prepararlo

            
    
              
  1. Subí el archivo a un servicio de almacenamiento, a una plataforma de video o a tu propio servidor.
    2. 
              
  2. Debería darte un enlace HTTPS directo al archivo. Verificá que las personas de la sala también puedan abrirlo y ver el video.
    3. 
              
  3. Pegá el enlace en este campo y cargalo en la sala.
    4. 
            

          

          

            
Opciones para alojarlo

            
    
              
  • Almacenamiento + enlace directo: Servicios como Cloudflare R2, Amazon S3 o Backblaze B2. Configurá el acceso al archivo y compartí su URL; algunos permiten servirlo mediante una CDN.
    • 
              
  • Tu propio servidor: Podés subir el video a tu hosting web, VPS o servidor personal y publicar un enlace HTTPS directo. Como alternativa, podés usar VideoPuente, un programa diseñado por mí para ese fin. El mismo te permite compartir/hostear un video de tu equipo mediante un enlace HTTPS. Descargalo acá.
    • 
              
  • Hosting de video: Bunny Stream, Cloudflare Stream o Vimeo procesan y reproducen videos. Sus enlaces de página o reproductor no sirven en este campo: necesitás que el servicio ofrezca un enlace directo a un archivo compatible.
    •

            Los enlaces normales de YouTube, Google Drive o las páginas de Vimeo suelen llevar a un reproductor, no al archivo.
          

        

        

          

            
          

        

      

    

    
      

        

          

            
            

              
Cine Juntos

              
Sobre este proyecto

            

          

          
        

        

          

            
Proyecto de código abierto (open source) que funciona como una base de plataforma con el propósito de facilitar la visualización sincronizada/compartida de contenido entre varios usuarios de manera sencilla y cómoda. Para ello, consta de la función de crear salas a las que se accede mediante un código de invitación. Cada sala cuenta con un chat y un reproductor, desde el cual se permite elegir el contenido que se desea ver vía una URL. La reproducción del contenido tiene una sincronización entre todos los usuarios, de manera tal, que lo que hace un usuario se refleja en los demás usuarios, incluidas funciones como reproducir, pausar y cambiar la velocidad, entre otras.

            

              
              

                
Esta página funciona como una demostración funcional del proyecto. No incorpora publicidad ni impone restricciones propias, más allá de las limitaciones de los servicios que utiliza.
