Cómo alojar y compartir un video

          

          
        

        

          

            Cine Juntos necesita un enlace HTTPS directo a un archivo de video accesible para las personas de la sala. Acepta MP4, WebM, Ogg, MOV y M4V; el enlace debe abrir el archivo, no una página de reproducción.
          

          

            
Cómo prepararlo

            
    
              
  1. Subí el archivo a un servicio de almacenamiento, a una plataforma de video o a tu propio servidor.
    2. 
              
  2. Obtené un enlace HTTPS directo al archivo y compartí uno que las personas de la sala puedan abrir. Si el enlace es temporal, pueden usarlo mientras siga vigente.
    3. 
              
  3. Pegá el enlace en este campo y cargalo en la sala.
    4. 
            

          

          

            
Opciones para alojarlo

            
    
              
  • Almacenamiento + enlace directo: servicios como Cloudflare R2, Amazon S3 o Backblaze B2. Configurá el acceso al archivo y compartí su URL; algunos permiten servirlo mediante una CDN.
    • 
              
  • Tu propio servidor: podés subir el video a tu hosting web, VPS o servidor personal y publicar un enlace HTTPS directo. Tené en cuenta el espacio disponible y el ancho de banda para quienes lo reproduzcan.
    • 
              
  • Hosting de video: Bunny Stream, Cloudflare Stream o Vimeo procesan y reproducen videos. Sus enlaces de página o reproductor no sirven en este campo: necesitás que el servicio ofrezca un enlace directo a un archivo compatible.
    • 
            

            

              Guía de acceso público de R2
              Enlaces MP4 de Cloudflare Stream
              Descargas MP4 de Bunny Stream
              Enlaces directos de Vimeo
            

          

          

            Los enlaces normales de YouTube, Google Drive o las páginas de Vimeo suelen llevar a un reproductor, no al archivo. Si el enlace es temporal, alcanza con que esté vigente cuando lo use la sala.
          

          

            
          

        

      

    

    
      

        

          

            
            

              
Cine Juntos

              
Sobre este proyecto

            

          

          
        

        

          

            
Cine Juntos es un proyecto de código abierto (open source) concebido como una base con el propósito de facilitar la visualización sincronizada de contenido entre múltiples usuarios de forma cómoda y sencilla. Para ello, permite crear salas a las que se accede mediante un código de invitación. Cada sala cuenta con un reproductor y un chat, y permite elegir el contenido que se desea ver y cargarlo en el reproductor. La reproducción se sincroniza entre todos los usuarios, incluidas funciones como reproducir, pausar y cambiar la velocidad, entre otras.

            

              
              

                
Esta página funciona como una demostración funcional del proyecto. No incorpora publicidad ni impone restricciones propias, más allá de las limitaciones de los servicios utilizados. El proyecto puede modificarse, adaptarse y alojarse libremente según las necesidades de quienes quieran utilizarlo.
