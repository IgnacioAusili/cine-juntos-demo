Antes de entrar a la sala

Conexión compartida de la sala

Para ver el contenido de manera compartida con otras personas y poder usar el chat, se necesita utilizar el servicio Firebase Realtime Database. Para integrar el servicio, se necesita una ApiKey que debes obtener desde tu cuenta de Google mediante Firebase Console. Es completamente gratuito, con límites mensuales. Solo se necesita configurar la primera vez.

01

Copiá el JSON de configuración

En Firebase Console → Configuración del proyecto → General → Tus apps → tu app web → Config. Si pegás solo una apiKey, debe ser del proyecto de esta plataforma. Para usar el tuyo, pegá el JSON de configuración completo (apiKey, authDomain, databaseURL, projectId y appId).

02

Activá el acceso anónimo

En Firebase Authentication → Sign-in method, habilitá Anonymous. La app crea una cuenta temporal para cada participante y usa esa sesión para acceder a la base.

Creá la base y sus reglas

En Databases & Storage → Realtime Database, creá una base. La app necesita acceso de lectura y escritura con sesiones anónimas, más específicamente, en este caso, a /rooms/{roomCode}. Eso puede configurarse en las reglas de la database, pero puede que por defecto ya venga permitido el acceso a cualquier ruta.

Pegá una apiKey o el JSON de configuración completo para comprobar la conexión.

Tu invitación lleva el ApiKey

Al compartir el link de invitación, para que los demás usuarios puedan comunicarse, en el link se cifra la ApiKey que ingresaste. De esa manera, comparten el servicio mediante TU ApiKey y la información queda guardada siempre que entren a una sala desde tu link de invitación. Si borrás la ApiKey de la URL y compartís el link, no podrán comunicarse aunque estén en la misma sala.

La ApiKey es única para el proyecto Firebase que configuraste desde tu cuenta de Google; se cifra de forma reversible en la URL. Como el mecanismo está en el código de la app, aporta solo una ofuscación básica; compartí el enlace únicamente con gente de confianza. Podés revocarla desde Google Cloud Console en cualquier momento.

¿Solo querés probar la página?

Entrá sin conexión. Vas a poder explorarla, pero no compartir la sala con otras personas.
